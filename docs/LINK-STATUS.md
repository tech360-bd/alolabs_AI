## 6. What is still not done

**All nine items of the previous §6 list are closed (2026-10-24).** Closing notes, one per item:

1. **Terminal primitive: larger text ramp and optional dot-grid background — done.**
   `typeRampFor('terminal')` boosts every role 1–2px (node-name 12→14, sublabel 9→10), SceneBuilder paints
   and measures on the skin's ramp (engines measure with the same ramp), the audit's typography check is
   skin-aware, and the dot-grid background exports in SVG/HTML as well as the canvas at
   `rgba(255,255,255,0.07)`. Terminal frames default to dots.
2. **Annotation: top-right and bottom-left margin placement — done.** `NoteSpec.at` accepts `top-right` and
   `bottom-left` in addition to the legacy anchors; leaders offset from the note's anchor edge.
3. **Semantic patterns: the nine named routing templates — done.** `semantic-patterns.ts` carries the full
   routing table plus one worked template per pattern; `/design` → Patterns is the living spec.
4. **Draw.io compressed XML import — done.** `inflate.ts` is a dependency-free RFC 1951 raw-DEFLATE decoder,
   verified against `zlib.deflateRawSync` at levels 0/1/6/9; `decodeDrawioPayload` unwraps draw.io's
   base64 + deflate-raw + percent-encoding, including URL-safe base64 and bare payloads.
5. **Output-spec ladders — done.** `output-spec.ts` implements format × size × detail × audience, the
   degrade ladder with fidelity ledger, and the checklist; `importDiagram` applies the dials before layout
   and the Import panel exposes them.
6. **Client profiles and URL-based skin onboarding — done.** `profiles.ts` (verbs, slugs, header format,
   project marker, stores) and `onboarding.ts` (CSS/JSON/markdown/HTML extraction, contrast checks, brand
   fidelity receipt) with full unit coverage.
7. **Browser checks — partially automated.** PNG export, motion playback and the marketing panel Templates
   list remain exercises for a real browser (jsdom cannot rasterise or play motion); everything testable
   around them is covered (exporter invariants, motion structure, asset serving incl. download headers).
8. **Integration suite (`prisma generate`, native `better-sqlite3`) — environmental, unchanged.** This
   sandbox cannot reach `binaries.prisma.sh` or `nodejs.org` (node-gyp headers), so the 8 integration files
   fail on missing native bindings exactly as before. Everything else passes.
9. **Backlog items in §4 — unchanged.** Each remains relevant to a surface in the product; none has been
   started. The status column in §4 is authoritative.
