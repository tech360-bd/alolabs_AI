# Resource compatibility matrix

> Phase 0 discovery snapshot · 2026-10-31 · baseline `d6774c0c131d460cae08b55ccde7eedc984843d1`
> Recommendations are not implementations or authorization. No application, dependency, schema, infrastructure or production changes were made.

## Existing stack compatibility

AgentOS is already a Next.js/React/TypeScript application, with Prisma 6.19.2 and production datasource policy requiring MySQL/MariaDB; SQLite is for development/tests. `pg`, Redis, object-store and Qdrant helpers exist but do not prove production services are provisioned. Root manifest declares Node >=20, npm >=10 and Bun 1.3.4; both npm and Bun lockfiles exist. CI uses frozen Bun installs. Current Next declaration (^16.4.3) and eslint-config-next (16.3.8) differ; validate supported release alignment later, do not change dependencies in Phase 0.

Python, Java, native desktop and model stacks must be separate processes/images, not imported into the web process. A separate service boundary does not remove license obligations. Browser resources and fonts currently include external hosts; audit offline behavior before claiming fully self-hosted UX. No native binary/model/dependency was installed.
